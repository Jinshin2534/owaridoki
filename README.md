# おわりどき (owaridoki)

みんなで話しているときに、会の終わりを「蛍の光」で知らせるWebアプリ。お店の閉店前と同じように、終わりの数分前から小さく流れ始め、だんだん大きくなり、アナウンスが入って、最後は曲がきれいに終わります。

公開URL: https://owaridoki.vercel.app

## 使い方
1. 終わる時刻(または「あと何分」)と、蛍の光を何分前から流すかを選んで「開始」。
2. 画面を開いたまま置いておく。残り時間が大きく出ます。
3. 流れ始め・1分前・終わる時刻に、チャイムとアナウンスが入ります。最後のひとことは書き換えられます。
4. 延びそうなら「+1分」「+5分」。終わる時刻を過ぎると、そのコーラスの最後まで演奏して終わります。

「試しに聞く」で、始める前に音量と声を15秒だけ確かめられます。

## しくみ
- 曲はスコットランド民謡「Auld Lang Syne」の旋律(パブリックドメイン)を、Web Audio で旋律・和音・ベースに分けて合成しています。録音や既存の編曲は使っていません。
- 音量は流れ始めの −30dB から終わる時刻の 0dB まで、dB で一直線に上がります(耳で一定のペースで大きくなるように)。
- アナウンスはブラウザの音声合成(日本語の声)です。読み上げのあいだは曲の音量を下げます。
- 背景のタブではタイマーが間引かれるので、曲の開始やアナウンスの合図は AudioContext の時計で起こしています。画面が消えないよう Wake Lock も取ります。
- 設定はこのブラウザにだけ保存します。サーバーはありません。

## 開発
```sh
pnpm install
pnpm dev     # 開発サーバー
pnpm test    # 予定の計算と旋律データのテスト
pnpm build
```
